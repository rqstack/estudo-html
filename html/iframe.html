----------------------------------------- PRINCIPAIS ATRIBUTOS ----------------------------------------- src - Define o endereço da página que será exibida. width - Define a largura do iframe. height - Define a altura do iframe. title - Descreve o conteúdo do iframe. - Importante para acessibilidade. loading - Controla o carregamento. - Valores: * eager (carrega imediatamente) * lazy (carrega quando necessário) allowfullscreen - Permite exibição em tela cheia. name - Dá um nome ao iframe para ser usado por links. sandbox - Aumenta a segurança restringindo ações da página incorporada. allow - Concede permissões específicas. - Exemplo: camera, microphone, fullscreen. ----------------------------------------- EXEMPLO SIMPLES ----------------------------------------- ----------------------------------------- EXEMPLO COM YOUTUBE ----------------------------------------- ----------------------------------------- EXEMPLO COM GOOGLE MAPS ----------------------------------------- ----------------------------------------- ABRINDO LINKS DENTRO DO IFRAME ----------------------------------------- Página 1 Página 2 O conteúdo será carregado dentro do iframe. ----------------------------------------- ATRIBUTO SANDBOX ----------------------------------------- O atributo sandbox aumenta a segurança.
